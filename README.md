# Thane Fest Landing Page 🎉

Welcome to the **Thane Fest Landing Page**, a beautifully crafted website for one of India’s most vibrant and culturally rich festivals. This project is built using HTML and CSS, with Font Awesome icons for social media integration.

## 📌 Features

- **Responsive Header** with a logo and fixed navigation bar
- **About Section** detailing the spirit and inclusivity of the festival
- **Event Highlights**
  - Live performances by Sunidhi Chauhan, Armaan Malik, and Darshan Raval
  - Descriptions and visuals of each artist
- **Culinary Experience**
  - Showcasing a mix of Chinese, Maharashtrian, and Italian cuisines
  - Supporting imagery of food items
- **Contact Us Form**
  - Basic form with validation for contact number
- **Footer**
  - Social media icons (Instagram and Facebook)
  - Legal info section


## 🛠️ Technologies Used

- **HTML5** for structure
- **CSS3** for styling
- **Font Awesome** for icons

## 🌐 How to Use

1. Clone or download the repository.
2. Open `index.html` in a web browser.
3. Ensure the `img/` folder and CSS file are correctly linked.

## 📣 Note

- This is a **static landing page**, meaning form submissions are not functional unless integrated with backend logic (e.g., via `form.py` or JavaScript).
